## Skill 列表

### [`sanwen`](./sanwen)

**适用场景**

当你与 AI / Agent 进行长对话，或完成一项复杂的分析、调查与讨论后，信息越积越多，事实、推测、结论和建议混在一起，让你难以看清当前结论、未决问题和真正需要自己判断的事项，甚至开始被 AI 的思路带着走。

**核心作用**

让 Agent 停止复述过程或直接替你下结论，重新梳理整段上下文，将其收敛为已确认的信息、仍未解决的问题和需要你拍板的选项，帮你快速找回判断重点，重新掌握对话和决策的主导权。

### [`mermaid-board`](./mermaid-board)

**适用场景**

项目进度、流程、结构需要一张能反复更新的示意图，但 AI 每次输出的文字计划太密、看不清自己在哪；直接让 AI 做 HTML 又太重，改起来贵、跨工具还带不走。

**核心作用**

用双文件维护一张图：Mermaid 源码存 `.md`（纯文本事实源，任何 AI 都能便宜地读和改），`build.py` 从固定模板生成 `.html` 查看器，双击浏览器打开、刷新即最新。统一状态色板（完成 / 进行中 / 未开始 / 风险），更新一次进度 = 改几行文本 + 跑一条命令。

**组成**

- `SKILL.md` — 规则：双文件铁律、子代理派发、节点文字规范、色板
- `template.html` — 固定壳（勿改样式），CDN 已锁版本
- `build.py` — `python build.py <md路径>` 生成 html，附基础检查
