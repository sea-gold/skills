# Mermaid Board

用两个文件维护一张可视化图：

```
docs/<图名>/
├── <图名>.md    ← Mermaid 源码，唯一事实源，更新图 = 改它
└── <图名>.html  ← 查看器，由 build.py 整体重新生成，禁止手工修改
```

用户通过双击 `.html` 在浏览器中查看，更新后按 F5 刷新。

## 派发规则：用子代理执行

画图/更新图是**读得多、产出落盘**的任务，不要在主会话直接做。主会话把任务派给子代理（subagent/Task），指令中写明：图名与路径、数据来源（哪些文档/档案）、事实截至日期、本次要改什么。子代理完成后只回一行：生成/更新了哪个文件、几张图、有无警告。

例外：只改一两个状态标签的小更新（如把某节点 `:::now` 改 `:::done`），且 md 路径已知，主会话可直接改完跑脚本，不必派发。

## 铁律

1. **改了 md 必须立刻重新生成 html**。两个文件不一致 = 任务未完成。
2. **html 只由脚本生成**：`python <skill目录>/build.py <md路径>`，整体覆盖同名 html。不读取、不修改、不手写 html。
3. **不修改 template.html 的样式与结构**。壳是死的，信息只住在 Mermaid 块里。
4. **不要自行验证渲染**（不装 mermaid-cli、不跑 npx）。脚本做基础检查；渲染是否正常由用户看图反馈。
5. 渲染依赖 CDN（版本已锁定），查看时需联网。

## Mermaid 编写约定

- 图类型默认 `graph LR`（横向流程）；层级/分支多时用 `graph TD`。
- 节点文字精简：一行主题 + 可选 `<br/>` 一行补充（日期、备注）。
- 一张图节点数 ≤ 12；超过则拆成多个 mermaid 块（各自加二级标题，html 中对应多个卡片）。

### 节点文字规范（防渲染失败）

- 节点文字**一律用双引号包裹**：`A["文字"]`。
- 文字内禁用 `#`、`&`、`<`、`>`（`<br/>` 换行是唯一例外）；括号、冒号等放在引号内即可。
- 换行只用 `<br/>`。

### 状态标色（统一色板，所有图通用）

节点挂 `:::状态` 标签。**每个 mermaid 块末尾都必须附带这四行 classDef**（各块独立渲染，缺了就没颜色）：

```
graph LR
  A["已完成的事"]:::done --> B["正在做的事"]:::now
  B --> C["还没开始的事"]:::todo
  C --> D["死线或风险"]:::risk

  classDef done fill:#e8f0e4,stroke:#7a9a6d,color:#3a5232
  classDef now  fill:#fdf3d7,stroke:#c9a227,color:#6b5510,stroke-width:2.5px
  classDef todo fill:#f4f3ef,stroke:#bbb,color:#666
  classDef risk fill:#fbe9e9,stroke:#b4232a,color:#7a1a1f
```

| 状态 | 含义 |
|---|---|
| `done` 绿 | 已完成 |
| `now` 黄（粗边） | 正在做的事，一张图最多一个；**没有正在做的事就不标，不要硬挑** |
| `todo` 灰 | 未开始（含"下一步"，不单设颜色） |
| `risk` 红 | 死线、保险丝、风险点 |

## 操作流程

**首次创建**：
1. 定存放位置：用户指定了明确路径/名字则从其；用户泛指（"新文件夹"之类）则用 `<图名>/` 并在回复中说明放在了哪。
2. 收集事实：明确本图数据来源（记忆档案、项目文档等）与事实截至日期。
3. 写 `<图名>.md`（格式见下）。
4. 跑 `build.py` 生成 html，告知用户双击查看。

**后续更新**：
1. **先问用户：上次更新（见 md 头部日期）之后有什么变化**，不要默认手头信息是最新的。
2. 改 md 中的 Mermaid（改状态标签、增删节点）。
3. 跑 `build.py` 重新生成，告知用户刷新即可。

## md 文件格式

````markdown
# <图标题>

> 更新于 <YYYY-MM-DD> · 事实截至 <YYYY-MM-DD>，来源 <一句话>

## <图一小标题>

```mermaid
<图内容，末尾带 classDef>
```
````

多张图 = 多个二级标题 + mermaid 块。classDef 必须留在 md 内（保证 md 在 GitHub / mermaid.live 单独打开时也有颜色），不由脚本注入。
