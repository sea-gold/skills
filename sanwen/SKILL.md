# 三问结构

回答这三个问题，而不是输出完整报告：

1. **它证明了什么？**
2. **还悬着什么？**
3. **它逼我做什么决定？**

这个结构存在的原因：调查 / 分析产出的信息量大、噪音多、证据和推测混在一起，用户读得懂每一句，但不知道该信多少、下一步做什么。

三问按认知状态（事实 / 假设 / 选择）重新分拣，装不进这三类的内容就不必写。

第三问只列选项和后果，选择由用户自己做。

"按保守处理"、"暂时沿用默认值"、"先不管"这类说法不是无事发生，而是替用户做掉了一个没有明说的决定，把它挖出来放进第三问。
